Política de Privacidad

Última actualización: 20 de septiembre de 2026

En BalkanBite respetamos la privacidad de nuestros usuarios. Esta política resume qué datos trata actualmente la aplicación, para qué se utilizan y qué proveedores técnicos intervienen.

1. Información que tratamos

  • Datos básicos de cuenta: cuando utilizas inicio de sesión, los datos necesarios para autenticar e identificar tu cuenta, como correo electrónico y la información básica de perfil que proporcione el proveedor de autenticación.
  • Datos introducidos en BalkanBite: despensa, lista de compra, recetas, menús, registros de uso y preferencias que guardes o confirmes.
  • Datos opcionales de salud: únicamente cuando decidas proporcionarlos para una función concreta. Los campos ausentes permanecen desconocidos y no se interpretan como respuestas negativas.
  • Entradas para funciones de IA: texto, contexto culinario y, cuando uses el escáner visual, la imagen que envías para analizarla.

2. Uso de la información e inteligencia artificial

Usamos los datos necesarios para autenticar tu cuenta, sincronizar la información que decidas guardar y ejecutar las funciones solicitadas por ti.

Las funciones generativas de IA de BalkanBite utilizan OpenAI GPT-5.6 Luna a través de la OpenAI Responses API. La aplicación envía al servidor únicamente el contexto necesario para la función solicitada y la clave de OpenAI se mantiene en el servidor. Nuestra integración solicita las respuestas con store: false.

Las estimaciones generadas por IA sobre cantidades, precios, caducidad, nutrición o salud no se convierten automáticamente en datos autoritativos de tu perfil o despensa.

3. Proveedores técnicos y seguridad

Actualmente utilizamos Firebase / Google para autenticación y sincronización en la nube y OpenAI para las funciones generativas de IA. Estos proveedores procesan la información necesaria para prestar esas funciones conforme a sus propios términos y políticas aplicables.

BalkanBite no vende datos personales a anunciantes. Las credenciales de servicios de servidor, incluida OPENAI_API_KEY, no deben exponerse al navegador.

4. Control y eliminación de datos

La aplicación distingue entre datos locales y datos sincronizados. El control de borrado local elimina únicamente datos de BalkanBite guardados en ese navegador o dispositivo y no implica borrar los datos cloud de una cuenta sincronizada.

El perfil dispone además de controles específicos para datos de salud. Para una solicitud de eliminación completa de cuenta o de datos sincronizados que todavía no disponga de un control dedicado en la interfaz, contacta con nuestro equipo de soporte.
